# E-Commerce-Sales-Database
A comprehensive MySQL-based E-Commerce Sales Database Management System featuring relational database design, CRUD operations, SQL joins, aggregate functions, subqueries, views, stored procedures, triggers, indexes, and sales analysis.
E-Commerce Sales Database Management System using MySQL

Project Overview

The E-Commerce Sales Database Management System is a relational database project developed using MySQL. It is designed to manage customers, products, categories, orders, order items, and payments for an e-commerce platform. The project demonstrates database design, SQL query writing, and sales analysis using real-world business scenarios.

---

Objectives

- Design a relational database for an e-commerce platform.
- Manage customer, product, order, and payment information.
- Perform CRUD (Create, Read, Update, Delete) operations.
- Analyze sales data using SQL queries.
- Demonstrate advanced SQL concepts such as joins, views, stored procedures, triggers, and indexes.
